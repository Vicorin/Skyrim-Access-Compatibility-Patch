## About the Mod

This is a set of scripts intended to be used alongside [Skyrim Access]()https://www.nexusmods.com/skyrimspecialedition/mods/181131) to improve compatability with various other community mods. The project is open source so you can build it yourself or add support for your own mods. It only installs the plugins for the mods you have installed.


## Installation and usage
Install the zipped mod archive from file in Vortex or MO2. It contains a FOMOD installer, allowing you to choose which patches you want to enable. It will automatically search for any compatible mods and select them for installation.

IMPORTANT: The Skyrim Access Compatibility Patch must be loaded after all mods it affects.
